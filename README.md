Ontwerp en bouw van de nieuwe site van de Indoor SGW, dé indoor eventingwedstrijd van Nederland in De Mortel.

- **Homepage:** `ontwerp/homepage.html`
- **Stijlgids:** `ontwerp/stijlgids.html`
- **Stylesheet:** `assets/css/indoorsgw.css`
- **Script:** `assets/js/indoorsgw.js`
- **Regels en werkwijze:** `CLAUDE.md`
- **Feedback:** `docs/feedback-log.md`

Statische site zonder build-stap. Elke push naar `main` zet Vercel automatisch online.
